# CRKP phage host-range triage: frozen protocol, v0.1
Frozen: 2026-09-29, before downloading or opening interaction outcome matrices. Owner scope accepted by main at 00:19 IST. Computational only; no release, clinical use or wet-lab execution.

## Question and claim boundary
Can capsule-aware phage receptor-binding protein (RBP)/K-locus features improve ranking of *existing naturally occurring* lytic phages against carbapenem-resistant Klebsiella pneumoniae (CRKP) strains, relative to published PhageHostLearn, on an independent infection matrix? This is a triage benchmark, not evidence that an engineered sequence kills resistant bacteria. WHO 2024 categorizes carbapenem-resistant Enterobacterales as critical, not K. pneumoniae as a separate entry [1]. Confirmation of strain-level carbapenem resistance requires original isolate metadata; unknown resistance stays unknown and cannot count toward a CRKP-specific claim.

## Data source lock and blind leakage audit
Training candidate: PhageHostLearn v2 Zenodo record 11061100 [2,3], DOI 10.5281/zenodo.11061100, files and immutable MD5s in `source-manifest.tsv`. Its authors report 2024 training derived from Beamud and Ferriol-Gonzalez, plus 28 resistant clinical isolates used for a distinct in-vitro test. Freeze author train/test assignments; in-vitro data must not seep into training.
External candidate: Townsend et al. 2021's infection matrix as assembled in the 2025 paper [4,5]. Source record 14852842, DOI 10.5281/zenodo.14852842, selected supplement bundles and MD5s in manifest. This is *candidate*, not established independent validation. Beamud 2023 and Ferriol-Gonzalez 2024 matrices in that same 2025 paper explicitly overlap the PhageHostLearn source data; exclude both as external tests. Determine Townsend row origins and independently verify raw isolate/phage accession IDs, source sequences and any train/test duplicates before opening labels. Perform exact and homologous phage/RBP-family, host genome and K-locus overlap audit using only IDs/sequences and capsule annotations; archive deterministic groups, exclusions and code. Candidate matching/no-match threshold, identity cutoff, family grouping and tie-breaking will be fixed in an audit appendix before accessing labels, not tuned against observed interactions. If independent eligible hosts, phages and tested pairs cannot support hit-rate@5, declare external gate unevaluable without replacing it with a convenient split. No untested matrix cell is a negative.

## Methods and prespecified outcome
Build reproducible RBP/K-locus ranking on author training data, preferably lightweight sequence features and capsule typing with leakage-safe grouping. Baseline: run published PhageHostLearn implementation/model on identical eligible candidate pairs, code [6], not a quoted literature score. Primary endpoint: paired per-host hit-rate@5, scored only when a held-out host has >=5 experimentally tested eligible phages and at least one confirmed positive; if fewer than 5, exclude host from primary rather than redefine k. Compare mean paired improvement with 95% host-cluster bootstrap confidence interval, 10,000 resamples, fixed seed 20260929. Gate passes only if its lower bound is >0, and all prereg safety screens pass for nominated candidates. Record eligible N and effective power before opening labels. Secondary only: AUROC, AUPRC, per-KL hit-rate, calibration, uncertainty and predicted breadth; no secondary rescues a failed primary. Host and phage cluster grouping precedes any fitting/tuning. No hyperparameter or feature search on held-out labels.
Mechanism check: compare full model against RBP-ablated and K-locus-ablated models on the same frozen test protocol, then check whether capsule-associated patterns align with published depolymerase annotations. A feature ablation is associative, not proof of physical binding. A negative or unevaluable gate is reported plainly, followed by a *new* separately locked hypothesis for any pivot.

## Safety and output gates
Exclude prophage/temperate candidates and genome sequences with known lysogeny, toxin, virulence, or antimicrobial-resistance cargo; use curated database searches plus manual review of uncertain hits. Keep missing annotations, incomplete genomes, ambiguous lifecycle and unknown cargo as unverified/excluded, never 'safe.' Prior to ranking nominations, prespecify and document a beneficial-commensal panel and a calibrated prediction threshold using training-only evidence. Flag or exclude every nominated candidate predicted to infect any panel member above threshold, but do not claim non-target safety from in-silico no-hits: host range requires empirical tests. Do not optimize breadth, environmental persistence or human/animal effects. The tool is a candidate-screening and benchmark auditor, no sequence designs, synthesis instructions or deployment recommendations in phase 1. One *existing* lytic phage plus resistant isolate can be named for qualified laboratory testing only if underlying provenance, phenotype, and safety checks pass; otherwise 'no nomination.'

## Artifacts and decision record
Phase 1 artifacts: accession/sequence provenance table, leakage audit, executable ranking and safety auditor, baseline reproduction, frozen held-out prediction file, paired uncertainty report, capsule mechanism ablation, and an honest report (figures, data dictionary, limitations). Public data only and no paid compute. Data, source code and results must be kept separately in a private repo and Drive according to user's program convention. Do not promise a positive result or claim top-lab validation absent measured external evidence.
