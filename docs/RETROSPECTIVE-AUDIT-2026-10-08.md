## What this does not verify

Arithmetic, input integrity and full prediction coverage do not prove that archived scores were generated by the stated fitted models. No fitted-model execution was rerun in this audit. Prototype and ablation pair scores and individual fold files are absent from the committed tree. The ablation summary can be independently checked from consolidated per-host rows, but its original summarizer requires ignored `ablation_parts` files that are not distributed.

The published-style summarizer likewise requires ignored individual folds and metadata; its archived prediction CSV enables a separate retrospective check, not a model refit. The original prototype script writes only host aggregates. `prep_training.py` uses a hard-coded old scratch directory rather than the configurable raw-input path used by later scripts. There is no pinned runtime lockfile in this lane. Recorded author-parameter runtime was Python 3.10.12, XGBoost 3.2.0, scikit-learn 1.7.2; the author repository lists Python 3.9.7, XGBoost 1.5.0, scikit-learn 0.24.2. Sorted phages and fixed seed also differ from the author run.

The prototype holds out single hosts; the author-parameter implementation holds out locus-similarity groups. They differ in feature order, weights and tree configuration. Their scores cannot establish a fair paired superiority result. No new independent cohort was opened. Existing external-gate exclusions are unchanged and were not re-adjudicated here.

Locus-only features are identical across candidate phages for a fixed held-out host, so its AUROC of 0.5 is structural. Its hit@5 depends on tied ordering. Feature-removal differences do not prove capsule binding or a biological mechanism. Bootstrap intervals resample fixed host results; they omit refitting variation and do not address data-source shift.
