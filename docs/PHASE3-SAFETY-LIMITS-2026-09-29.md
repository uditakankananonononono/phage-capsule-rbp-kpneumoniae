# Phase 3: bounded cargo search and safety gate

**October 8 evidence qualification:** the summary and summarizer code below were inspected, but original search reports, logs and predicted-ORF files are not committed. Their hashes alone cannot certify execution. Totals are internally consistent; zero hits remain a reported limited-search result, not an independently verified safety result. See `RETROSPECTIVE-AUDIT-2026-10-08.md`.

All 105/105 PhageHostLearn RBP-embedded phages have deposited FASTAs in https://zenodo.org/records/11061100 (`phages_genomes.zip`, MD5 `f43159fd3473e2d22a56fec27e8d443c`). This does **not** establish verified closed genomes, complete ends, purity, lytic lifestyle, narrow host range, or safety.

A bounded **known-cargo protein search** was completed for all 105, using Prodigal 2.6.3 `-p meta` to call 8,382 putative ORFs and NCBI AMRFinderPlus 4.2.7 `--plus` on those predicted proteins, database release 2026-08-07.1. All 105 reports completed; zero reference matches were reportable under these thresholds and calling method. This is **not** a negative AMR/toxin/virulence safety result: translated nucleotide BLASTX exceeded the local 1.9-GiB memory limit, and the successful protein-only mode misses genes that were not called, remote homologs outside the curated database, noncovered toxin/virulence classes and other functional hazards. No claim is made that all relevant viral toxins are captured by a database built chiefly around bacterial AMR and selected virulence genes. The original phage FASTA headers, including any claim of completeness, are not independent proof of complete ends. Per-phage predicted-ORF counts, report hashes and methods are recorded in `code/cargo_screen_limited.json`; reproducible checks in `code/summarize_cargo_screen.py`. NCBI tool documentation: https://www.ncbi.nlm.nih.gov/pathogens/antimicrobial-resistance/AMRFinder/ and https://github.com/ncbi/amr .

**Lifecycle:** No validated whole-genome temperate/lysogeny screen was completed. No phage can be labeled obligately lytic from sequence name, GenBank description, absence of an integrase call, or phenotype in another strain. Curated viral gene classification and manual review remain necessary, followed by experimental validation. A no-hit from AMRFinderPlus has no lifecycle meaning.

**Beneficial-commensal off-target:** No prespecified commensal isolate/sequence panel with matched receptor metadata, host-range ground truth and accession-level provenance is available in this phase, so no commensal off-target screen was run. In-silico host prediction would not substitute for plating/efficiency-of-plating assays on a defined panel. Treat all 105 as unassessed for off-target effects.

**Decision:** All 105 remain ineligible for nomination. No clinical recommendation, sequence modification, phage design, or lab procedure follows from this bounded audit. External benchmark constraints are unchanged: Townsend is underpowered/outcome-exposed and Ghatbale is RBP-excluded; no frozen endpoint may be opened or redefined to improve the result.
