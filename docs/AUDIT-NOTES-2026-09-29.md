# Audit notes (2026-09-29; not a prereg amendment)

- PhageHostLearn Zenodo 11061100's RBPbase has 274 RBP records/105 phage IDs, and Locibase has 200 host IDs. Townsend 2021 Table 2 lists 30 phages: 26 lytic, 4 temperate. No exact phage name or host-ID string match. This metadata fact does not establish biological independence.
- Townsend Table 2's 30 project IDs have all been resolved to ENA sequence accession IDs using the ENA portal API, saved as `audit/townsend-accessions.json` with source descriptions. All 30 FASTAs were retrieved and hashed after bounded retries. None of the 30 has an exact genome SHA256 match to the 105 genomes in PhageHostLearn v2. Hash equality is not a homology analysis, so leave the external gate blocked pending RBP-family, genome-neighbor and host-K-locus overlap.
- Four K. pneumoniae strains in Townsend Table 1 can be matched by exact NCTC number to the culture collection's carbapenemase reference strain listing: 13439, 13440 (VIM-1), 13442 (OXA-48), 13443 (NDM-1). Carbapenemase listed is evidence of resistance mechanism, but susceptibility phenotype needs a direct match when claiming phenotypic resistance.
- The original Townsend infection matrix is Figure 3 (colored image); categories distinguish plaque formation from clearance/no effect. Do not score a mere lawn-clearing spot as productive infection. Figure interpretation must be independently checked against original pixels. No outcome labels are in the current audit artifacts.
- The 2025 paper's Supplementary Data 2-6 workbook contains per-phage depolymerase KL targets but does not replace the full 30x24 strain-level Townsend matrix. Two other infection matrices in that paper (Beamud, Ferriol-Gonzalez) overlap PhageHostLearn sources and remain barred from external evaluation.
